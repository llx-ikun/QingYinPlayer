# 轻音播放器

一个**纯本地**的 Windows 音乐播放器：导入本地音乐与视频、播放控制、歌单管理、歌词同步显示、视频画面播放。
QQ 音乐桌面端风格的深色/浅色双主题界面，无边框圆角窗口，全中文，无需联网，数据全部保存在本机。

技术栈：Python 3.13 + PySide6 6.12（Qt Multimedia / FFmpeg 后端）+ mutagen + JSON 持久化。

---

## 功能

| 模块 | 功能 |
|---|---|
| 音乐导入 | 文件夹递归扫描 / 多选文件 / 拖拽到窗口；后台线程 + 进度显示 + 可取消 |
| **视频导入与播放** | 本地视频与音乐混排导入；双击视频直接进入视频页显示画面并播放；等比缩放黑底、进度/音量/队列/收藏与音乐一致；`F11` 全屏、`Esc` 退出；「音乐模式」随时切回且**不中断声音与进度** |
| 播放控制 | 播放/暂停、上一首/下一首、进度拖动跳转、音量调节/静音 |
| 播放模式 | 顺序播放、列表循环、单曲循环、随机播放 |
| 歌单管理 | 新建/重命名/删除、添加歌曲、移出歌曲、拖拽排序、上移/下移 |
| 「我喜欢」 | 行内心形 / 播放栏心形一键收藏；独立虚拟歌单视图，持久化保存 |
| 歌词显示 | 同名 `.lrc` 自动匹配、内嵌歌词（ID3 USLT/SYLT、FLAC LYRICS、MP4 ©lyr）、手动绑定 `.lrc`/`.txt`、批量导入 `.lrc`/`.txt` 自动识别归属（含浏览器下载的纯文本歌词，自动剔除歌名/作词/作曲等头部信息）；逐行同步高亮、平滑自动滚动、点击跳转；**歌词动效**（无动效仅高亮 / 放大当前行 / 逐字显示未唱不显示 / 逐字上色未唱淡显，设置里单选）；**双语歌词**（原文行 + 译文行交替时自动配成一句：原文大字、译文小字，整句一起高亮/放大，逐字动效原文打完接着打译文）；**整体偏移微调**（±0.5 秒，写回 .lrc） |
| 联网歌词 | 本地无歌词时联网匹配，**LRCLIB + 网易云 + QQ音乐三源并行取最优**（均免密钥直连）；五级来源：手动绑定 → 同名 `.lrc` → 内嵌 → 本地缓存 → 联网；命中即写缓存、断网照常显示；检索中显示进度、命中后标注来源（LRCLIB/网易云/QQ音乐）；负缓存 7 天，右键可强制重新匹配 |
| 歌词对齐 | 纯文本歌词（无时间轴）可**本地对齐**成带时间轴的 LRC：离线分析音频节奏（解码 + 静音检测 + 时间轴分配），**无需 Key、不上传音频**；导入纯文本后自动询问、歌词区右键「转成 .lrc 文件（本地近似对齐）」；转换后生成**同名 .lrc 到歌曲同目录**，切歌自动识别；不准可用右键「整体提前/延后 0.5 秒」微调。**近似不够就手动打轴**：右键「逐句打轴（手动卡时间）」，播放中按 `空格` 逐句盖时间戳、`Backspace` 回退、打完自动写 `.lrc` —— 时间完全由你决定，不再受算法误差影响 |
| 数据目录 | 数据位置可选择：设置 → 存储，可搬到任意盘 / 恢复默认；软件目录放 `data/` 即变便携版，整个文件夹拷走即带走曲库 |
| 音乐库 | 全部导入歌曲；最近播放（自动）；全局搜索（标题栏）；按标题/艺人/专辑/时长/添加时间排序 |
| 封面 | 自动提取内嵌封面（MP3 APIC / FLAC / MP4 / OGG）；无封面生成渐变占位图；歌单封面取第一首 |
| 界面 | 无边框圆角窗口 + 自定义标题栏（前进/后退/刷新/搜索/窗口三键，可拖拽、可边缘缩放）；双主题（默认浅色「冷调月白」，深色「星月」夜空）；左下浮动工具条 |
| 其他 | 启动恢复上次曲目与播放位置、设置记忆（昵称/主题/音量/模式）、视图历史前进后退、文件丢失友好提示、toast 提示 |

支持音频格式：**mp3 / flac / wav / m4a / aac / ogg / opus / wma**
支持视频格式：**mp4 / mkv / mov / avi / wmv / flv / webm / m4v**

> 实际可播放性由系统 FFmpeg 后端决定。实测音频 mp3/flac/wav/ogg 全部正常；视频已实测 MJPEG AVI（自造夹具）与 Qt 后端可解码的容器。**容器可导入 ≠ 该容器内所有编码都能解码**，不支持的编码会走既有错误提示与跳过链。

## 快速开始（普通用户）

1. 双击 `dist/QingYinPlayer.exe`（单文件便携版，首次启动需解压，约 2-5 秒）；
   或进入 `dist/QingYinPlayer-Portable/` 双击里面的 `QingYinPlayer-Portable.exe`（目录版，启动更快）。
2. 点击左下角「导入音乐」→ 选择文件夹或文件；也可以把音乐文件/文件夹直接拖进窗口。
3. 双击列表中的歌曲开始播放。

> - exe 文件名使用英文是为规避部分 Windows 显卡驱动（Intel 核显 + D3D9on12）对中文程序名的兼容问题——中文 exe 名会在这些机器上启动崩溃；**程序界面、窗口标题全部为中文，不受影响**；
> - 首次启动若被杀毒软件拦截，请选择「允许」——本软件未做数字签名，属误报；
> - **只能运行 `dist/` 里的 exe**；`build/` 目录是打包过程的中间文件，不可运行；
> - 数据默认保存在 `%APPDATA%\轻音播放器\`（歌单、设置、封面、曲库）。可在「设置 → 存储」里改到其他盘，或在软件目录放一个 `data/` 文件夹启用便携模式（数据随文件夹走）。

## 快捷键

| 按键 | 功能 |
|---|---|
| `空格` | 播放 / 暂停 |
| `Ctrl + ← / →` | 上一首 / 下一首 |
| `← / →` | 快退 / 快进 5 秒 |
| `↑ / ↓` | 音量加 / 减 5% |
| `Esc` | 清空搜索框（**全屏时优先退出全屏**） |
| `F11` | 视频画面全屏 / 退出全屏 |
| `Ctrl + F` | 聚焦搜索框 |
| `Alt + ← / →` | 视图后退 / 前进 |

**打轴模式**（歌词右键「逐句打轴（手动卡时间）」进入，结束时自动退出）：

| 按键 | 功能 |
|---|---|
| `空格` | 给当前高亮这一句盖上此刻的时间戳，前进到下一句 |
| `Backspace` | 撤掉上一句的时间戳，高亮退回上一句 |
| `Esc` | 结束打轴（没打满会询问；放弃则不写盘） |

> 打轴期间 `空格` 让给打点，播放/暂停暂停用；打完最后一句自动结束并写同名 `.lrc`。

## 开发运行

环境要求：Python 3.13+（虚拟环境）。

```bash
# 1. 创建虚拟环境并安装依赖（国内网络建议用镜像）
python -m venv .venv
.venv/Scripts/python.exe -m pip install -i https://mirrors.aliyun.com/pypi/simple/ -r requirements.txt

# 2. 运行（开发模式）
.venv/Scripts/python.exe main.py

# 3. 运行测试（604 项：单测 + offscreen E2E，29 个独立进程）
.venv/Scripts/python.exe run_tests.py
# 无显示器的 headless 环境（如 CI）自动加 QT_QPA_PLATFORM=offscreen

# 4. 打包（单文件版 + 目录版 + 冒烟测试；图标缺失时才自动补一个占位）
.venv/Scripts/python.exe build.py
```

> **本仓库开发环境注意事项（WorkBuddy 沙箱）**：
> - pip 官方源极慢，依赖安装统一走阿里云镜像；
> - 沙箱会经 `PYTHONPATH` 注入文件删除守卫，会拦截 pip/PyInstaller 的批量文件覆盖，
>   因此这类命令需要加 `env -u PYTHONPATH` 前缀（在普通 PowerShell/CMD 中无需此步）。

## 已知事项

- **打包依赖 cffi**：本地歌词对齐用 miniaudio，它的 `_miniaudio.pyd` 在 C 层 `import _cffi_backend`，PyInstaller 的 PE 依赖扫描看不到这种运行时导入，所以 `build.py` 显式加了 `--hidden-import _cffi_backend`；`main.py --smoke` 还会探一次解码器，缺了直接让构建失败，避免「界面正常、点本地对齐才报缺组件」的半成品出厂；
- **构建日志不是 UTF-8**：windowed 产物（PyInstaller `runw.exe`）重定向到文件时按系统代码页写（中文 Windows 为 cp936），且不认 `PYTHONIOENCODING`；`build.py` 读日志时 utf-8 → gbk 回退，`tests/test_build.py` 有回归。
- **m4a/aac**：无真实样本在本环境验证过（无转码工具），代码路径与 mp3/flac 相同，FFmpeg AAC 解码为标准能力，预期可用但未实测；
- 构建沙箱无音频渲染设备，「声音输出与播放进度自动推进」已在开发环境之外验证（状态机/seek/音量/解码加载均通过自动化测试），最终声音效果请以本机双击运行为准；
- 超大曲库（>5000 首）首次导入会稍慢，列表渲染为逐行控件，滚动流畅度以千首级为设计目标；
- 本版本不做：在线音乐/云同步、标签编辑、迷你模式（见 DESIGN.md 的 Won't 清单）。
