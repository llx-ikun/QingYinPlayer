# 一个 122MB 的开源播放器，把我硬盘里那堆「没人管的歌」救回来了

> 写给所有还在用本地音乐文件、却被流媒体客户端越做越重的人。

---

## 先说痛点

我硬盘里有一万多个音频文件。十年攒下来的：早年从 CD 抓的、朋友传的、现场版、冷门翻唱、自己剪的。

它们有一个共同点——**没有任何一个主流播放器愿意好好对待它们**。

打开某个国民级音乐客户端，首页是直播、是商城、是「猜你喜欢」；导入本地文件夹要翻三层菜单；好不容易导进去了，歌词要么没有，要么时间轴错得离谱。至于那个我没买的会员，它会很礼貌地提醒我：这首歌需要 VIP。

我也试过那些「极客播放器」。功能确实强，但界面停留在 2008 年，想换个配色得先读懂一份配置文件。

后来我想要的东西其实很简单：

- 打开就能放我的歌，**不联网也能用**
- 歌词能跟上，最好能一个字一个字亮
- 界面别丑，别让我每次打开都想关掉
- 别偷偷上传我的文件

找了很久，最后找到这个：**轻音播放器**（QingYinPlayer）。一个纯本地、全中文、MIT 开源的 Windows 播放器，**122MB，解压双击就能用，不用装。**

用了两周，我觉得值得写一篇。

---

## 一、它真的不联网

这是它最大的立场。

**你的歌、你的歌单、你的播放记录，全部只存在本机**（默认 `%APPDATA%\轻音播放器\`）。它没有账号、没有云端、没有「登录后同步」。

甚至可以做**便携版**——在软件目录里放一个 `data/` 文件夹，整个目录拷到 U 盘，插到另一台电脑上，歌单、封面、歌词、设置原封不动跟着走。

这点对很多人可能无所谓，但对我这种「不想让播放器知道我半夜在循环哪首歌」的人来说，是刚需。

---

## 二、歌词这块，是我见过最用心的之一

大部分播放器的歌词功能，做到「能滚动」就结束了。这个不是。

**① 五级来源，层层兜底**

手动绑定 → 同名 `.lrc` → 音频内嵌歌词（MP3 的 USLT/SYLT、FLAC 的 LYRICS、MP4 的 ©lyr）→ 本地缓存 → 联网匹配。

联网也不是随便找一个源：**LRCLIB + 网易云 + QQ音乐三源并行，取最优**，命中就写进缓存，之后断网照样显示。还会告诉你这句歌词是从哪来的。

**② 纯文本歌词能自动变成时间轴**

这是我最喜欢的功能。

网上下的歌词经常是一坨纯文本，一行一行整整齐齐，就是没有一个时间戳。别的播放器只能干瞪眼，它可以直接：

**离线分析音频**（解码 → 静音检测 → 时间轴分配），把纯文本「变」成带时间轴的 `.lrc`，生成到歌曲同目录，切歌自动认。

**不上传音频、不需要 API Key、完全离线。**

**③ 算法不准？那就手动打轴**

更狠的是，它知道算法会不准，于是给了个手动模式：

右键「逐句打轴」，然后在播放中按**空格**——听到哪句就盖一个时间戳，自动跳到下一句；打错了按 **Backspace** 回退。打完自动写 `.lrc`。

**时间完全由你决定。** 这一点，我在任何商业播放器里都没见过。

**④ AI 逐字对齐（可选）**

如果你追求极致的「一个字一个字亮起来」，它还能调用本地的 Whisper 模型做强制对齐：识别演唱 → 把词级时间戳映射回你原本的歌词文字 → 再把每个字的边界吸附到换气和咬字的位置。

注意：这条是**可选**的，模型不随软件分发，需要你自己在设置里按需下载（tiny/base/small 三档）。下载走国内镜像，不用翻墙。

而且作者做了个很克制的设计：**匹配置信度太低就判定失败，绝不写入一份错的歌词**。宁可没有，也不给你假的时间轴。

## 三、它还能放视频，而且切换不打断

支持 mp4 / mkv / mov / avi / wmv / flv / webm / m4v。

双击视频直接进视频页出画面，进度、音量、队列、收藏跟音乐完全一致；`F11` 全屏，`Esc` 退出。

我一开始以为这是个噱头，直到发现一个细节：**从视频切回「音乐模式」，声音和进度不中断**。

也就是说你可以一边听 MV 的声音，一边翻歌单。这种地方骗不了人——是认真做过交互才想得到的。

## 四、界面不像开源项目

四套配色：

| 主题 | 风格 |
|---|---|
| 月白 | 浅色，带装饰底纹（默认） |
| 星夜 | 深色，带装饰底纹 |
| 曜石 | 纯黑 |
| 珍珠 | 纯白 |

无边框圆角窗口，自定义标题栏（前进/后退/刷新/搜索/窗口三键），可以拖拽、可以拉边缩放。背景图案（星空、云海）还能和任意主题自由搭配。

**纯黑和纯白这两套做得挺讲究**——纯黑不是把背景刷成 `#000` 就完事，面板和背景特意差了一档亮度，否则整个窗口会「糊成一块」，看着像没渲染完。

## 五、那些让人愿意留下来的细节

- **拖拽排序**：歌单、音乐库、「我喜欢」都能直接拖，拖动时显示插入位置的横线，松手即保存。不排序的状态下也能拖，会自动切到「自定义顺序」。
- **双语歌词**：原文行 + 译文行自动配成一句，原文大字、译文小字，整句一起高亮/放大，逐字动效是原文打完接着打译文。
- **当前播放的这句永远自动放大**——不需要你设置。
- **启动恢复上次的曲目和播放位置**。
- **文件丢失有友好提示**，不是甩你一个报错。
- **数据目录可迁移**：设置里能把整个曲库搬到别的盘，带进度、可取消。

## 说点缺点，别被我忽悠

**第一，只有 Windows。** Windows 10/11 x64，没有 Mac、没有手机、没有 Linux。

**第二，没有在线音乐。** 它就是放你硬盘里的东西。想听新歌，请自己去买、去下。

**第三，没有标签编辑。** 改 ID3 信息得用别的工具。

**第四，没做数字签名。** 首次运行时杀毒软件可能会拦一下，选「允许」即可——这是未签名 exe 的常见误报，不是病毒。

**第五，超大曲库要有点耐心。** 官方说法是千首级流畅，五千首以上首次导入会慢一些。
