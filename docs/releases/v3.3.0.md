# 轻音播放器 v3.3.0 交付说明

**发布日期**：2026-11-03
**类型**：功能版本（次版本号 +1）

---

## 这一版加了什么

**动态背景**：播放歌曲时，窗口底层会有一层跟着音乐起伏的实时动画。

设置 → 背景 → 「动态背景」，四套风格：

| 风格 | 长什么样 | 适合 |
|---|---|---|
| 呼吸光晕 | 三团柔和光团藏在面板后面，随音乐膨胀/收缩 | 日常听歌，最不打扰 |
| 音频环 | 一圈短柱随节奏起伏，像可视化器 | 想「看见」音乐的时候 |
| 粒子浮尘 | 细密浮点缓慢上浮，亮度随音量呼吸 | 长时间当背景，最安静 |
| 极光流 | 三条宽幅色带缓慢流动，能量大时更亮更厚 | 氛围感优先 |

**它是真的跟着歌走**，不是循环播放的动图：播放时后台把整首歌解码成一条
每秒 20 档的音量包络（4 分钟的歌约 0.3 秒），落盘缓存，同一首歌第二次播放直接命中。
背景亮度就按当前播放位置去这条曲线上查值。

---

## 怎么用

1. 打开 设置 → 背景
2. 在「动态背景（跟随音乐）」里点一个风格
3. 想换主色：同一页的「颜色」按钮（动画就用这个色）
4. 想更克制：把「不透明度」往下拉；想更暗：调「暗化」

动态背景与「背景图案」（星空 / 云海）**互斥** —— 背景只有一层，选一个会顶掉另一个。

  并把三条带的中心压到 0.24 / 0.50 / 0.76 保证不出画

## 兼容性

- **数据**：`BackgroundConfig.type` 新增 `live`，旧配置照常读取；读不懂的类型值仍退回 `none`
- **缓存**：`%APPDATA%/轻音播放器/energy/<track_id>.json`，删掉只是下次重算 0.3 秒
- **依赖**：**零新增**。绘制是 QPainter，解码复用已有的 miniaudio
- **体积**：安装包大小不变（无素材文件）

---

## 已知边界

- 音频环反映的是**整体响度**，不是真实频段（Qt 6 不给频谱）；柱高差异来自相位错落
- 视频播放时也有动态背景，但视频本身盖满画面，基本看不到
- 极端情况下（音频格式不支持解码）会一直停在时间驱动模式，背景仍会动，只是不跟随音量
